## 为什么加入任务面板

此前场景已有传送、抓取能量核心、插入供电、开门和出口结算，但首次接触游戏的人可能不知道先去哪、抓起核心后放在哪里，也可能看不到当前是否成功。第 6 周在维修舱加入英文世界空间任务面板，显示当前状态，并提供 `SHOW HELP` / `HIDE HELP` 和 `RESET MISSION` 两个可操作按钮。帮助内容只列三步：传送到蓝色维修区、把核心放入橙色插槽并松手、穿过舱门到达出口。状态文字随任务进度变化；重置按钮调用原任务的重置逻辑。

面板应由原有 Meta Rig 的控制器射线点击，场景只保留一个 EventSystem。第 5 周的移动、抓取和声音继续作为完整流程的一部分。上述是界面设计和源码目标；实际可用性须以 Unity Play、APK 和试玩记录为准。

- 组织者是否事先确认射线点击、Grip、传送和重置可用：`待填写`

**开始时只对试玩者说：**“请尝试恢复空间站供电、打开舱门并到达出口。你可以阅读游戏里的提示；遇到问题请说出你现在想做什么。”不要提前告诉他每一步或指出按钮。Quest 测试先说明安全边界、如何随时暂停；出现不适立即停止。

**建议时间安排：**

1. `0:00–1:00`：戴好头显或进入电脑模拟器，确认画面清晰、安全与控制器输入。只说明如何暂停测试。
2. `1:00–7:00`：试玩者独立完成主任务。观察他是否注意到任务面板、是否主动打开 `SHOW HELP`，是否能传送到蓝色维修区、Grip 抓起青色核心、在橙色插槽松开、理解绿色供电和开门反馈、最终到达 `EXIT`。
3. `7:00–9:00`：如果还未用过按钮，请他尝试用控制器射线指向并以 Trigger 点击 `SHOW HELP` / `HIDE HELP` 和 `RESET MISSION`；如果按钮或操作失败，记录具体画面与动作，不要替他点击。
4. `9:00–10:00`：问“哪一步最不清楚？”“任务状态和帮助有没有帮到你？”“按钮是否容易看清、瞄准和点击？”记录原话要点，不推断其感受。

操作参考仅供组织者在测试后核对：任务正常顺序为“传送 → 抓取 → 插槽松开 → 舱门开启 → 出口”。原任务逻辑要求核心先被抓起，且放手时靠近插槽。抓住核心时按 `RESET MISSION` 会提示 `RELEASE CORE / TO RESET MISSION`，松手后自动重置；玩家已经在舱门后时须先回主舱再按重置，完成状态显示 `RETURN FOR REPLAY`。电脑键盘 `R`、Quest 右控制器 `B` 也是原有重置入口。模拟器键位随当前输入绑定而变，不预设 `Y/U/T/M` 永远适用。
