# E-07 station hardware

Original procedural meshes for this course project, generated by
`Assets/Editor/StationHardwareBuilder.cs`. No downloaded models or textures are
used. The meshes and matching materials may be used and modified with the project.

- E-07 cartridge: metal cage, end caps, cyan crystal and rotating power glyph.
- Coupler: beveled socket rim, recessed well, twelve light segments and three clamps.
- Airlock: two beveled door panels, inset armor, locks, frame and indicator lamps.

Meshes are stored as Unity `.asset` files, so the built scene does not depend on
running the builder at runtime. `Course > Week 06 > Build Team UI Scene` regenerates
the complete current team scene from the Week 05 source. Rebuilding replaces that
generated team scene; save any manual scene work separately first.

Materials use URP Lit for metal/ceramic and URP Unlit for indicator surfaces.
These bright surfaces do not require bloom. Decorative objects have no physical
colliders; the core has one capsule collider and the doorway has one blocking
box that is released only after the opening sequence completes.
